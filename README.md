A program that writes one joke about working beside AI coding agents — the agent demos perfectly in rehearsal, then crashes live in front of fifty people, and the crash is the one piece of code it ever wrote that behaved exactly like its human's — to `/output/entry.txt`. Python 3.13, standard library only, no network at runtime, deterministic: every run writes the same bytes.

## Run it

```sh
python3 main.py
```
